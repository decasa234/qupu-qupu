# IKMC — International Kangaroo Mathematics Contest (Grades 1–4)

Official past papers from the Pakistan IKMC chapter (Kangourou Sans Frontières / KSF),
scraped from the official site. **Publicly and freely downloadable** — these are the real
full contest papers, not samples.

- Source index: https://ikmc.kangaroo.org.pk/past_papers/3162
- Per-year pages: `https://ikmc.kangaroo.org.pk/docs/<id>` → direct PDFs under
  `https://ikmc.kangaroo.org.pk/uploads/ikmc/documents/*.pdf`
- Organizer: Kangaroo (KSF) Pakistan — https://kangaroo.org.pk/

## Level ↔ grade mapping (Kangaroo)
| Level | Classes / Grades | In this folder? |
|---|---|---|
| **Pre-Ecolier** | Class 1 & 2 | ✅ (grades 1–2) |
| **Ecolier** | Class 3 & 4 | ✅ (grades 3–4) |
| Benjamin | Class 5 & 6 | ✗ (out of scope) |
| Cadet | Class 7 & 8 | ✗ |
| Junior | Class 9 & 10 | ✗ |
| Student | Class 11 & 12 | ✗ |

Grades 1–4 = **Pre-Ecolier + Ecolier**. Both levels grabbed for every year, plus the
year's combined **answer key**.

## Format (read off the papers)
- 120 minutes, multiple choice (options A–E).
- Sections by points: **Section One = 3-point**, then 4-point, then 5-point problems.
- Heavy on visual/spatial reasoning, patterns, and logic (kid-friendly diagrams).
