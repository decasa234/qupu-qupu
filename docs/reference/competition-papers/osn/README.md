# OSN / KSN — Olimpiade Sains Nasional, Matematika SD (Indonesia)

Real past papers for Indonesia's national science olympiad, **math, SD (elementary) level**.
Called **KSN** (Kompetisi Sains Nasional) ~2020–2022, otherwise **OSN**. These are
government/Puspresnas contest papers; widely circulated free.

- 31 PDFs, years **2007–2025**, all levels of the cascade:
  **Kecamatan** (district) → **Kabupaten/Kota** (regency) → **Provinsi** (province) →
  **Nasional** (national, incl. teori/eksplorasi/semifinal/final rounds).
- Content-verified real (e.g. 2024 Provinsi cover: "Soal Olimpiade Sains Nasional Bidang
  Matematika Jenjang Sekolah Dasar — Tingkat Provinsi — Tahun 2024", CONFIDENTIAL watermark).
- Some files include pembahasan (worked solutions); many are soal-only.

## Source / provenance
No official Puspresnas archive exists publicly. Free copies live on Indonesian education
blogs that re-host scans on Google Drive — the reliable aggregators:
- https://mathcyber1997.com/download-soal-osn-ksn-bidang-matematika/
- https://www.defantri.com/2017/10/kumpulan-soal-osn-matematika-sdmi.html
- https://www.folderosn.com/

## Note on grade level
OSN **SD** is elementary but olympiad-hard (roughly grade 4–6 difficulty). It's the youngest
OSN tier — a stretch for QUPU's grade 1–3, useful mainly as a harder reference / stretch set.
OSN **SMP** (junior-high) papers are also freely available from the same sources if needed
later (not downloaded here — out of grade range).
