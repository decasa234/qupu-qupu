# JISMO — Japan International Science & Maths Olympiad

No free past papers were locatable as of this writing. JISMO is the newest/smallest of the
three competitions and distributes papers via its official app and registration flow rather
than a public archive.

- Levels: Primary 1&2, Primary 3&4, Primary 5&6.
- Official site: https://www.jismo-educational.org/home
- YouTube: `@JISMOEDUCATIONAL`
- A stray JISMO **Primary 5** practice paper surfaced publicly (out of grade 1–3 scope).
