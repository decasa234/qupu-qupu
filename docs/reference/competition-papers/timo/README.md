# TIMO — Thailand International Mathematical Olympiad

Run by Olympiad Champion Education Foundation (same family as HKIMO). Divisions:
Kindergarten, Primary 1–6, Secondary. Rounds: Preliminary (Heat) → Final → Global.

## Files (6)
- `TIMO-Sample-AllGroups.pdf` — official sample paper covering every division (KG → Secondary)
  **with answer key**. Source: https://www.thaiimo.com/sample-paper.html
- `TIMO-2020-2022-Primary{1..5}.pdf` — FERMAT Education bilingual (English/Vietnamese)
  compilation booklets, one per primary level. Each ~5 MB, ~60–70 pages, and contains the
  real **Preliminary Round** + **Heat/Final Round** papers for **2020–2021 and 2021–2022**
  with answer sheets. Cover: "TIMO — KHỐI n — © FERMAT EDUCATION".
  Source: Vietnamese school site `c1nguyendu.pgdcujut.edu.vn` (FERMAT-published).

For grades 1–4, the relevant booklets are **Primary 1–4** (Primary 5 included as a stretch).
Content-verified real (Primary 3 cover + Preliminary/Heat sections confirmed).

## Availability note
Individual dated TIMO papers (specific heat/mock rounds) mostly live behind paywalls
(Scribd/Course Hero/pdfcoffee) or FERMAT's email-gated portal — excluded. The Primary 1–5
booklets above are the best free, real source. No free KG/Primary 6/Secondary *question*
booklet was found beyond the all-groups sample paper.
