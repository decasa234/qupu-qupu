# SASMO Syllabus — Grades 1–3

Singapore & Asian Schools Math Olympiad (SIMCC). Grade 1 added in 2021.
Source: official SASMO sample-paper-and-syllabus PDF (in this folder) + https://sasmo.sg/.

## Syllabus (identical across Primary 1–6; depth/difficulty rises by grade)

1. **Arithmetic and Statistics**
2. **Geometry and Mensuration**
3. **Solving word problems using the model method** (or any other non-algebraic method)
4. **Non-routine problem solving** — number patterns, divisibility tests, spatial
   visualisation, logic problems, and **simple cryptarithms**

> The four headings are fixed; what changes by grade is the size of numbers, number of
> conditions in logic problems, digits in cryptarithms, and figure complexity.

## Paper format (per public sources — verify against a current paper)
- 25 questions, two sections: **Section A** (multiple choice) + **Section B** (non-routine).
- No calculators. Scored with a starting-points + per-question scheme.

## Representative sample questions (from the official sample PDF)

- **Grade 2 — logic/arrangement:** "A box contains 4 balls (red, green, yellow, blue) in a
  row. Green is not 2nd. Red is neither 1st nor last. Yellow is not next to red nor blue.
  Find the order." (Answer: Blue, Red, Green, Yellow)
- **Grade 3 — non-routine division/sharing:** "Least number of cuts to cut 16 identical
  sausages so they can be shared equally among 24 people?" (Answer: 16)
- **Grade 4 — cryptarithm (alphametic):** `AM + LAP = PEEL`, all different letters = different
  digits; find PEEL. (Answer: 1009)

## Signature archetypes to cover in drills
number-arrangement logic · truth/order clues · divisibility · simple cryptarithms ·
spatial/figure comparison · non-routine sharing/cutting · number patterns · model-method
word problems.
