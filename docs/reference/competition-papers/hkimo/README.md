# HKIMO Past Papers — Primary 1–3

Past papers for the **Hong Kong International Mathematical Olympiad (HKIMO)**, Primary 1, 2 and 3,
collected as reference material for authoring QUPU / WMI problems.

Organised by grade. The **round** is in each filename (`heat` = Heat Round 初賽, `semifinal` = Semi-Final 晉級賽):

```
primary-1/   primary-2/   primary-3/
  hkimo-<year>-<round>-primary-<grade>.pdf
```

**20 papers total.** Each is a 25-question paper across Logical Thinking, Arithmetic, Number Theory,
Geometry, Combinatorics; bilingual EN/中文 (some EN/ID). Every paper's header was visually verified
for correct year / grade / round (slugs on the source sites were unreliable).

### Why 2023 is Semi-Final, not Heat
The **2023 Heat Round** primary papers are not freely available anywhere I could find — only the
**Semi-Final 2023** papers are. They are included here, clearly labelled, as the closest substitute.
(2023 Semi-Final P2 exists online only inside multi-paper practice compilations, so it is omitted.)

### Remaining gaps (not freely available)
These exist only in the paid OCEC / Thai IMO store (thaiimo.com/store, ~$6–10 each):
**2021 P2 & P3, 2022 P3, 2023 Heat (all grades).** Also: no 2021/2023 P2/P3 heat papers, and 2026
papers, were posted to any free source at collection time.

## Sources & format

- **2018** — original vector PDFs from
  [defantri.com](https://www.defantri.com/2018/11/kumpulan-soal-hikmo-2018-dan-timo-2017.html)
  (Google Drive mirror). Text is selectable.
- **2019–2025** — captured from publicly-viewable documents on Scribd by rendering each page of the
  embed reader to a high-resolution image and assembling them into a PDF. These are **image-based**
  (page renders): legible, with all questions and figures intact, but text is not selectable.

Question papers only — no answer keys. (A community "HKIMO Primary 1 2018–2023 answers" compilation
exists on Scribd if keys are wanted.)
